CPG · Agentic AI

Agentic Order Management System

A production multi-agent system where different LangGraph agents handle different user intents, routed at runtime. It maintains session state across turns and persists conversation history and user context in a relational database, then executes complex multi-step workflows through LangGraph graphs and subgraphs. Every LLM call, tool invocation, prompt, and response is fully traceable through LangSmith, a monitoring dashboard visualizes application health and performance, and a CI/CD pipeline automates testing, LLM evaluation, and deployment — agentic AI built to be observable, governed, and shippable.

CPG / Pharma · Platform

Self-Healing Data Pipeline

High-volume CPG and pharma pipelines break in predictable ways — a supplier changes a file format, a column drifts, a feed arrives malformed — and each break used to mean a 2 a.m. page and a manual fix. This system pairs a deterministic supervisor with LLM repair agents and policy-driven schema governance: it classifies drift, repairs what it safely can, and halts for review when a change would violate policy — all while keeping the Bronze layer immutable. Pipelines recover on their own, on-call load drops, and governance is never traded away for uptime.
